Application (Frontend + API) Vector Store LLM (external) Documents

Documents are chunked and embedded into ChromaDB (one-time setup). For each question, the backend retrieves the most relevant chunks, builds a grounded prompt, and asks Gemini to answer only from that context — returning the answer with source citations.
