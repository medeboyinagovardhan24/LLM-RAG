1 · High-Level Architecture

Layered design: presentation → application (FastAPI) → data (vector store + files), with Gemini as an external LLM service.

2 · Document Ingestion Pipeline

What happens when a user uploads a PDF — validation, de-duplication, chunking and indexing.

flowchart LR
    U["📄 PDF Upload"] --> V["Validate
type · size (≤20MB) · %PDF magic bytes"]
    V --> H["SHA-256 Hash
duplicate check"]
    H --> E["Extract Text
pypdf · per page"]
    E --> C["Chunk
800 chars · 100 overlap"]
    C --> S["Embed + Store
ChromaDB"]
    S --> M["Metadata tagged
filename · page · chunk"]

3 · Query Flow (Retrieval-Augmented Generation)

What happens when a user asks a question — retrieve relevant chunks, ground the prompt, generate a cited answer.

flowchart LR
    Q["❓ Question"] --> RT["Retrieve
top-K = 10 · semantic search"]
    RT --> DD["De-duplicate
unique chunks"]
    DD --> PR["Build Grounded Prompt
context + strict 'answer only from context' rules"]
    PR --> GEN["Gemini · Generate"]
    GEN --> ANS["✅ Answer + Sources
file · page · chunk"]

    RT -. queries .-> VDB[("ChromaDB")]
